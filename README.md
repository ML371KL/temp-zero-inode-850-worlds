# Миры ставок семейства 850 — общий источник

Один источник записей миров ставок (N «нормализация», H «высокие ставки надолго», M «рыночный как есть») и банковской
надстройки объёмов для всех моделей семейства 850. Мир пересобирается **один раз** здесь; модели принимают версию своей
командой `ops/tools/adopt_worlds.py --version <v>`. Это общий источник данных, а не общее ядро: код моделей остаётся
независимым (решение владельца 10.10.2026), каждая модель держит побайтовую копию записи и сверяет её с индексом.

## Что здесь

| Путь | Что |
|---|---|
| `versions/<v>/` | версия — после выпуска не меняется: паспорт `VERSION.yaml`, запись `record/` (CRLF, побайтово у моделей), входы `inputs/`, рецепт версии `recipe/`, описание рецепта для моделей `doc/` (`<<book_gen>>` — имя книги модели), надстройка банков `bank/` (`worlds_bank.json` + два формата входа сборщиков: черновик с диапазонами ЦБ и лист сектора с готовыми путями), лист окна и фактов `evidence/` (скрипты, выходы, опись первички `SOURCES.json`), `NOTES.md` |
| первичка | сами документы и снимки (ЦБ, Росстат, MOEX) в публичный репозиторий не кладутся — только хэши и выписки чисел; файлы лежат в приватной папке `850-worlds-evidence/<v>/` рядом с репозиторием |
| `versions.json` | индекс версий (хэши всех файлов, даты, подписи для книг); пишет `tools/worlds.py index`, читают команды приёма моделей |
| `recipe/worlds_recipe.py` | текущий рецепт (следующая версия собирается им); обязан воспроизводить все прежние версии — новая механика только ключом входов |
| `recipe/WORLDS-RECIPE.md` | описание рецепта |
| `bank/build_overlay.py`, `bank/build_overlay_sector.py` | сборщики надстройки `worlds_bank.json` из черновика и из листа сектора (копии сборщиков книг Сбербанка и Т-Технологий) |
| `tools/worlds.py` | `verify`, `index`, `show`, `new`, `build` |
| `tools/rollout.py` | запуск приёма версии по всем моделям реестра `models.yaml` (пути — от папки семейства `FAMILY_ROOT`) и сводная таблица |
| `.github/workflows/verify.yml` | CI: индекс, версии, тесты (Python 3.12) |
| `tests/` | тесты правил рецепта и источника |

## Новая версия (один исполнитель)

1. `python -B tools/worlds.py new --version 1.8 --from 1.7` — каталог версии с входами и черновиком прошлой.
2. Правка входов (`inputs/worlds_inputs.yaml`: прогноз ЦБ, опрос, ОНДКП, окно рынка, факты полугодия), черновика
   надстройки и паспорта; лист окна и фактов — в `evidence/`.
3. `python -B tools/worlds.py build --version 1.8` — запись текущим рецептом (CRLF на любой ОС), копия рецепта в
   версию, надстройка из черновика.
4. `python -B tools/worlds.py index`, `python -B tools/worlds.py verify`, `pytest -q tests`.
5. Коммит, тег `worlds-1.8`.
6. `python -B tools/rollout.py --version 1.8` — приём во всех моделях (ветка в каждой, без выкладки) и сводная таблица:
   сдвиг точки и медианы, печать, гейты, CI, красные флаги. Выкладка — по одному «да» владельца, по очереди.

Пробная версия (другое окно, другой ввод) — `--status trial`: модели принимают её только сухим прогоном.

## Python

3.12+ (`tools/worlds.py` отказывает на 3.11: сумма float там считается иначе — проверка окна записи 1.7 на 3.11 падает).
В текущем рецепте усреднение окна — `math.fsum` (запись 1.4 и 1.7 воспроизводится и на 3.11, и на 3.12).
