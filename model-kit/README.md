# Набор модели для приёма миров

Образец того, что каждая модель семейства несёт у себя:

| файл | куда в модели | что |
|---|---|---|
| `adopt_worlds.py` | `ops/tools/adopt_worlds.py` | команда приёма версии миров по манифесту модели — **движок, один на семейство**: копия модели побайтово равна этому файлу (правил модели не знает) |
| `test_worlds_dependents.py` | `tests/test_worlds_dependents.py` | сторож: книга стоит на версии своего состояния, все читатели миров названы в манифесте, копия движка равна образцу на коммите приёма |
| — | `data/assumptions/worlds_dependents.yaml` | манифест модели: что копировать из версии, какие ключи писать из индекса, правила пересчёта чисел, команды сборки, числа книги, таблицы, тексты, эталоны, журналы — **все различия моделей здесь** |
| — | `data/assumptions/worlds_state.json` | состояние: версия миров книги, хэши файлов версии, коммит источника и хэш образца движка на нём (пишет команда, руками не править) |
| — | `ops/tools/worlds_rules.py` (или листы `evidence/`) | правила модели: функции `f(ctx) → {"file", "values", "decimals", "replace", "text_values"}` для чисел, зависящих от миров |

Правка движка — только здесь, новым коммитом источника; модели получают её копией файла (новые модели — с образцом
кода), шаг `state` команды пишет в состояние хэш образца на коммите приёма (`engine_sha256`). Тест модели сверяет с ним
хэш своей копии без сети; `adopt_worlds.py --check` — ещё и с образцом источника на коммите приёма, если источник
рядом. Копия, правленная в модели, — красный тест.

Виды шагов манифеста: `install`, `state`, `set`, `rule`, `run`, `loop`, `numbers`, `quick`, `gates`, `journal`; у любого
шага — `when: change` (только при смене версии миров) и `check: false` (докстринг `adopt_worlds.py`).
Отчёт команды — схема `adopt-worlds-report-v1`; его читает `tools/rollout.py`.

Числа книги (`numbers`) — из полного шага таблиц (`results.json`, 2 000 прогонов): «было» — таблицы книги до приёма,
«стало» — после шага таблиц. Ими пишутся отчёт команды, сводка `tools/rollout.py` и журналы (`{n.median_after}` …).
Формат — JSON `{"point", "median", "low", "high", "print", "band", "worlds": {…}, "runs", "seed"}` (числа — в рублях на
акцию; `print` — печать медианы на витрине): команда модели (`cmd`, пишет `file`) или выборка `fields` прямо из таблиц.
Быстрые числа (`quick`, малая полоса) — только ранняя остановка по сдвигу медианы до тяжёлых шагов (порог
`stop.median_print_steps` шагов печати).
