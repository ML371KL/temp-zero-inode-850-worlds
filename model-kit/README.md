# Набор модели для приёма миров

Образец того, что каждая модель семейства несёт у себя (код моделей независим — это копии, а не общий модуль):

| файл | куда в модели | что |
|---|---|---|
| `adopt_worlds.py` | `ops/tools/adopt_worlds.py` | команда приёма версии миров по манифесту модели (движок; правил модели не знает) |
| `test_worlds_dependents.py` | `tests/test_worlds_dependents.py` | сторож: книга стоит на версии своего состояния, все читатели миров названы в манифесте |
| — | `data/assumptions/worlds_dependents.yaml` | манифест модели: что копировать из версии, какие ключи писать из индекса, правила пересчёта чисел, команды сборки, таблиц, текстов, эталонов, журналов |
| — | `data/assumptions/worlds_state.json` | состояние: версия миров книги и хэши файлов версии (пишет команда, руками не править) |
| — | `ops/tools/worlds_rules.py` (или листы `evidence/`) | правила модели: функции `f(ctx) → {"file", "values", "decimals"}` для чисел, зависящих от миров |

Первый образец — книга Совкомбанка (ветка `worlds-1.7` репозитория `temp-zero-inode-850-svcb`). Правка движка в модели —
переносится сюда и в остальные модели; расхождение копий видно сравнением хэшей.

Виды шагов манифеста: `install`, `state`, `set`, `rule`, `run`, `quick`, `gates`, `journal` (докстринг `adopt_worlds.py`).
Отчёт команды — схема `adopt-worlds-report-v1`; его читает `tools/rollout.py`.

Быстрые числа (`quick`) — команда модели пишет JSON: `{"point", "median", "low", "high", "print", "worlds": {"N", "H",
"M"}, "runs", "seed"}` (числа — в рублях на акцию; `print` — печать медианы на витрине).
